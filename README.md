# Expense-tracker
Python Expense Tracker project

## 📌 Project Description
This is a simple console-based Expense Tracker application built using Python.  
It helps users add expenses, view expenses, and calculate total spending.

## 🛠️ Features
- Add expense amount
- View all expenses
- Calculate total expense
- Simple menu-driven program

## 💻 Technologies Used
- Python
